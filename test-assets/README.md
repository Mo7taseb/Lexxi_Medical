# Test Audio Assets

This directory contains audio files used for testing the Lexxi Medical transcription system.

## 🎵 Available Test Files

### **Arabic Audio**

- `ar2.mp3` - Arabic language test recording

### **English Audio**

- `en.mp3` - English language test recording
- `consultation-voice-note.mp3` - Medical consultation recording in English

### **Mixed Language**

- `mix1.mp3` - Mixed language test recording

## 🔧 Usage

These files are used for:

- Testing voice transcription accuracy
- Validating Arabic language support
- Testing mixed language detection
- Medical consultation transcription testing
